# PathContext v1.0.0

First citable release of the code and compact reproducibility artifacts associated with the ACM BCB 2026 paper “Patch-Level Tissue Context Improves Learning from Frozen Pathology Foundation Model Embeddings.”

## Included

- Frozen-embedding extraction and baseline evaluation.
- Patch-, graph-, and local-neighborhood context benchmarks.
- Paper split lists and compact benchmark outputs.
- Scripts for regenerating summary plots and qualitative panels.
- Canonical ACM citation and Zenodo-ready metadata.

Paper: https://doi.org/10.1145/3807503.3820870
